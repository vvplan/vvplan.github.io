# “虚谷计划”项目官方主页

## 简介

虚谷计划是一个包含硬件和软件的开源教育项目，由一线教师联合高校、创客空间和科技企业共同发起，致力于为中国青少年提供完整、开放、可复制、可实践的人工智能与科技教育解决方案。

## 历史

虚谷计划最早从 2018 年发起，一开始以创客教育为核心方向，先后形成了虚谷号、掌控板、虚谷物联和乐造模块等项目。其中掌控板项目发展良好，已成为国内中小学创客教育最常用的开源硬件之一，虚谷物联项目中的 MQTT 服务器“SIoT”也成为中小学物联网教学的重要工具。

2022 年之后，虚谷计划团队逐步转向人工智能教育，XEduPro、OpenHydra、QuickForm、QuickClass、XEdu Client 等新项目持续加入，构建起覆盖开源硬件、物联网、人工智能工具与教学平台的完整教育生态。
